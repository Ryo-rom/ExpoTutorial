# Learning Expo / React Native

React Native と Expo を学習するために、[公式チュートリアル](https://docs.expo.dev/tutorial/introduction/)（日本語版）を写経しながら進めているリポジトリです。

## 目的

- React Native / Expo の基礎（コンポーネント、Expo Router によるファイルベースルーティングなど）を習得する

これらは、将来的に個人用アプリ（メモ管理アプリ）を自作するための準備学習です。

## この内容について

本リポジトリのコードは、Expo公式チュートリアルの内容に沿って書かれた学習用コードです。
オリジナルのアイデア・実装ではなく、チュートリアルを写経・理解するための記録として公開しています。

- Tutorial: https://docs.expo.dev/tutorial/introduction/
- Expo / React Native は MIT License の下で提供されています

## 環境

- Expo
- TypeScript
- Expo Router
